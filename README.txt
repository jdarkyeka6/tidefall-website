# Tidefall Website

The official website for **Tidefall**, an interactive fantasy universe featuring characters, books, lore, quizzes, games, and the Tidefall Academy.

## Live Website

Visit **tidefall.com.au**

## Main Sections

* Explore the Tidefall universe
* Meet the main characters
* Discover Tidefall Academy
* Read about the books
* Take character and academy quizzes
* Explore interactive activities and hidden secrets

## Main Characters

* Harper Vale
* Jasper Holloway
* Lily Hart
* Ava Rees

All four main characters are members of **Brannor**.
